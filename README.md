## 📖 Sobre o Projeto

A **LUME Boutique** é um e-commerce de moda feminina desenvolvido para oferecer uma experiência sofisticada de compra online.

O projeto foi criado com foco em:

- ✨ Design moderno e elegante
- 📱 Responsividade completa
- ⚡ Alto desempenho
- 🧩 Arquitetura escalável
- 🎨 Interface premium
- 💻 Código organizado e de fácil manutenção

Inicialmente, os pedidos são finalizados através do **WhatsApp**, permitindo um atendimento personalizado. Toda a arquitetura foi planejada para receber futuramente um backend completo com autenticação, banco de dados, gestão de estoque e integração com gateways de pagamento.

# ⚙️ Instalação

Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/lume-boutique.git
```

Entre na pasta

```bash
cd lume-boutique
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm run dev
```

Abra no navegador

```
http://localhost:5173
```
